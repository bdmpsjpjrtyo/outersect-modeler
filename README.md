## Overview

Modeler lets sound designers build custom physical instrument models by configuring resonant bodies, exciter types, and coupling mechanisms, exporting the result as a standalone playable instrument.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Outersect Modeler** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Resonator Builder** | Assemble custom resonant bodies from string, plate, and air components |
| **Exciter Library** | Pluck, strike, bow, and blow exciter types with tunable parameters |
| **Coupling Network** | Define energy transfer paths between resonators and body components |
| **Export Format** | Export finished models as AAS Chromaphone-compatible instrument files |
